# Sketch Manifest

## Design Direction

DESIGN.md와 `src/theme/tokens.ts`가 이미 확정한 디자인 시스템을 그대로 따른다 — 담담하고
절제된 톤, 웜 오프화이트 배경(`#F4F1EA`) 위에 올리브그린 accent(`#7C8660`) 단 1곳,
3단 타이포그래피(SF Pro 시스템 폰트 / SF Mono 모노스페이스 / Newsreader 이탤릭 세리프),
8px 스페이싱 스케일, bounce/spring 모션 금지, 진행률/완료 수치 절대 노출 금지(CRITICAL).
이 스케치들은 새 미학을 탐색하지 않는다 — 이미 잠긴 디자인 시스템이 실제 화면에서
어떻게 읽히는지 검증하는 용도.
