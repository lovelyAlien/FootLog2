# Sketch 001: Today View

## Design Question

Phase 4의 레이아웃 구조는 이미 `04-UI-SPEC.md`가 잠갔다(지도 + 3단 스냅 바텀시트 +
플로팅 체크인/재센터 버튼 + 하단 탭바). 이 스케치는 "어떤 구조가 맞나"를 묻지 않는다 —
이미 확정된 구조가 실제 화면 크기(390×844pt)에서 DESIGN.md 토큰 그대로 조립됐을 때
정말 잘 읽히는지, 그리고 바텀시트 드래그 같은 인터랙션이 실제로 자연스러운지 확인한다.

## How to View

```
open .planning/sketches/001-today-view/index.html
```

## Variants

- **A: 체크인 있음(기본)** — 오늘 체크인 3건, 저장된 핀(accentSoft teardrop) + 궤적선(accentSoft, 2px 실선). 바텀시트 핸들을 드래그하면 CLOSED(80px)↔OPEN 사이를 실시간 추적하며, 손을 떼면 220ms로 가까운 쪽에 스냅한다(더블클릭으로도 토글). 체크인/재센터 버튼이 시트 상단을 그대로 따라간다(D-05).
- **B: 빈 상태(오늘 첫 체크인 전)** — 핀도 궤적선도 없는 지도, 시트엔 "아직 기록이 없어요 · 체크인하면 지도가 채워져요" 한 줄만. 점선 플레이스홀더나 숫자 배지 없음.
- **C: 체크인 진행 중** — 확인 핀(accent)이 지도에 뜨고 바텀시트는 완전히 사라진 채(D-04) 액션카드가 그 자리를 대신한다. 이미 저장된 핀들은 계속 보인다. 하단 탭바는 계속 탭 가능(D-09) — "캘린더"를 눌러도 막히지 않는다.

## What to Look For

- **바텀시트 드래그 체감** — CLOSED에서 OPEN까지 손가락을 따라오는 느낌이 자연스러운가, 220ms 스냅이 너무 빠르거나 느리지 않은가.
- **OPEN 상태에서도 지도 컨텍스트가 남는가** — UI-SPEC이 "100% 풀스크린 시트는 만들지 않는다"고 못박은 부분(상단에 지도가 항상 조금 보임).
- **저장된 핀(accentSoft) vs 확인 핀(accent) 색상 구분** — Variant C에서 동시에 보이는 두 팔레트가 "이미 기록됨 vs 지금 진행 중"이라는 위계로 실제로 읽히는가.
- **리스트 행의 담담함** — 화살표/뱃지/칩 없이 시간(모노스페이스) + 메모 미리보기(세리프 이탤릭)만 있는 것이 허전하게 느껴지는지, 아니면 의도한 대로 절제돼 보이는지.
- **탭바 틴트** — 활성 탭이 iOS 기본 파란색이 아니라 `textPrimary`(웜 니어블랙)로 렌더링되는지(UI-SPEC이 명시적으로 짚은 기본값 함정).
- **우측 하단 "토큰 라벨" 토글** — 주요 요소에 실제 색상/스페이싱 토큰명을 오버레이해서 보여준다. 특정 요소가 어떤 토큰을 쓰는지 바로 확인 가능.
