# FootLog

## What This Is

FootLog는 iOS 전용, 완전 로컬 위치 체크인 저널입니다. 하루 동안 사용자는 버튼 하나를 눌러
지금 있는 위치를 기록하고(선택적으로 사진/메모 첨부), 오늘의 체크인들을 지도 위 바텀시트
리스트로 확인하며, 하루를 짧은 2문항 회고로 마무리합니다. 1단계는 정확히 한 명의 사용자
— 창업자 본인 — 를 위해 만들어지며, 백엔드/클라우드에 투자하기 전에 1~2주 실사용
트라이얼을 통해 이 습관이 실제로 자리 잡는지 검증하는 것이 목적입니다.

## Core Value

체크인을 남기는 행위가 실제 매일의 사용을 버텨낼 만큼 마찰이 적어야 합니다 —
이 습관이 형성되지 않으면 앱의 다른 어떤 부분도 의미가 없습니다.

## Context

- **1인 검증용 제품.** 1단계 동안의 유일한 사용자는 창업자 본인, 본인 소유 iPhone 사용. 1단계에는 다중 사용자·인증·계정 개념이 전혀 없음.
- **명시적 kill condition**(유예된 백엔드 마일스톤 착수 여부를 가르는 go/no-go 기준): 1~2주 트라이얼 동안 (a) 알림이 정상적으로 울렸음에도 3일 이상 연속으로 체크인이 0건이거나, (b) 트라이얼 기간 전체 메모/사진 첨부율이 20% 미만이면 중단하고 진행하지 않는다. 그 외의 성공 여부는 정량적 완료율 기준이 아니라 창업자 본인의 정성적 판단("실제로 습관이 됐고 계속 쓸만한지")으로 정한다.
- **디자인 시스템이 모든 UI 결정을 지배** — `DESIGN.md` 참고(모든 시각/UI 작업 전에 반드시 읽을 것; 명시적 사용자 승인 없이 벗어나지 않음).
- **진행률/완료 수치는 UI 어디에도 노출 금지** — 오늘 뷰, 회고, 캘린더 등 전체에 걸친 CRITICAL 등급 디자인 원칙이며 화면별 선택사항이 아님. AI가 생성한 목업이 여러 차례 다시 넣으려다 거부당한 이력 있음.
- **아직 요구사항으로 확정되지 않은 열린 질문**(TODOS.md에 노출됨, 창업자 판단 필요, 자동결정 대상 아님):
  - Apple Journal(iOS 17+ 내장 저널링 앱) 대체 가능성 질문 — 창업자의 go/no-go 판단 대기 중, 두 차례의 독립 리뷰에서 각각 지적됨.
  - 사진 권한 거부 vs 리사이징 실패 문구가 현재 서로 다른 3가지 원인(카메라 거부/라이브러리 거부/리사이징 실패)에 하나의 인라인 실패 문구를 공유 중 — 문구 분리 필요(P3).
  - 하루 첫 체크인의 보상 신호가 반게이미피케이션/반스트릭 원칙과 진짜 긴장 관계에 있음 — 빠른 수정이 아니라 진지한 디자인 고민이 필요하다고 플래그됨(P3).
  - 시간대 변경 시 반복 트리거 동작은 실기기를 확보한 뒤(M1 이후) 실기기 검증이 필요함(P2).
  - 확인 핀 드래그 보정 제스처에 VoiceOver 대체 경로가 없음 — 인지된 gap, 1단계의 유일한 사용자가 VoiceOver 사용자가 아니라 우선순위 낮음(P3).
- **정리 필요:** `TODOS.md`에 오래된 항목 2개가 남아 있어 사용자가 직접 정리해야 함 — 이미 해결된 "kill condition 부재" P1 항목(Key Decisions 참고)과, 현재의 정성적 kill condition이 아니라 이미 폐기된 정량적 게이트를 여전히 인용하고 있는 2단계 "Depends on" 문구. 둘 다 1단계 작업을 막지는 않음.

## Constraints

- **플랫폼**: 네이티브 iOS 전용, Expo/React Native, EAS Dev Client 필수(Expo Go 불가) — `react-native-maps`가 네이티브 모듈을 필요로 함.
- **타겟 기기**: 창업자 본인 소유 iPhone, 390×844pt 기준(iPhone 12/13/14/15급), 세로모드 전용, 시스템 Dynamic Type만 지원.
- **오프라인 우선**: 1단계는 네트워크 의존성 전무 — 백엔드도 외부 API도 없음. 이 때문에 날씨 자동 캡처도 제외됨.
- **위치 권한**: 포그라운드 전용(백그라운드/"항상 허용" 없음) — 앱스토어 심사 마찰 회피를 위한 의도적 결정.
- **알림 스케줄링**: 반복 캘린더 트리거(`repeats: true`, minute 컴포넌트만) 사용 필수, 매일 재스케줄링 방식 금지 — iOS의 64개 대기 알림 한도 이내 유지.
- **Apple Developer Program**: 유료 등급($99/년, 창업자가 이미 보유) — 무료 등급의 7일 프로비저닝 만료로 인한 로컬 SQLite 데이터 유실 리스크가 해소됨.
- **스키마**: `Checkin`과 `DailyReflection` 테이블, `PRAGMA user_version` + 마이그레이션 함수로 버전 관리(빌드 도중 이미 한 번 변경된 적 있음 — 고정된 스키마로 취급하지 말 것).
- **사진 저장**: 반드시 `documentDirectory` 하위에 저장, `cacheDirectory`는 사용 금지(OS가 캐시를 비우면 저장된 `photoPath` 참조가 조용히 깨질 수 있음).
- **디자인 시스템**: 3단 타이포그래피(SF Pro / SF Mono / Newsreader 이탤릭 세리프), 단일 accent 컬러 `#7C8660`을 정확히 6곳의 승인된 용도로만 사용, 8px 스페이싱 스케일, bounce/spring 모션 금지, 44×44px 터치 타겟, 4.5:1 이상 명도 대비, 진행률 수치 전면 금지. 상세는 `DESIGN.md` 참고 — 명시적 사용자 승인 없이 벗어나지 않음.
