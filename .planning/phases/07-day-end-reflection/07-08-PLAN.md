## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS 알림 응답(`NotificationResponse`) → 앱 라우팅 | OS가 전달한 데이터가 앱의 화면 이동을 유발하는 경계 — 이 앱이 지금까지 갖지 않았던 새 진입점이다 |
| 잠금화면(인증 전) → 알림 표시 내용 | 기기를 잠근 상태에서 제3자가 볼 수 있는 표면 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-21 | Tampering | 알림 페이로드를 통한 딥링크 조작 | mitigate | 이동할 라우트를 알림 페이로드에서 읽지 않는다 — 하드코딩된 문자열 `'/reflection'` 하나뿐이라 URL 인젝션 표면이 존재하지 않는다. 알림 콘텐츠에 `data` 필드를 추가하지 않으며 wiring 테스트가 `content.ts`의 `data:` 부재를 게이트한다 |
