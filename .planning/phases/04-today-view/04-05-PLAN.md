    **로더.** `const reloadTodayCheckins = useCallback(() => { ... }, [db])`를 만든다. 본문은 `getTodayCheckins(db, resolveLocalDateKey(new Date()))`를 호출해 성공 시 `isMountedRef.current`가 true일 때만 `setTodayCheckins(rows)`를 하고, 실패 시 `console.error('Failed to load today\'s check-ins', error)`를 남긴다(프로미스 미삼킴 규약 — 저장소 전역 계약). 날짜 키를 화면 상태에 캐시하지 않고 호출 시점마다 새로 계산한다 — 자정을 넘겨 앱을 계속 켜둔 경우에도 다음 로드가 새 날짜를 보게 하기 위함이다.

    **호출 지점 4곳.** 정확히 아래 네 지점에서만 `reloadTodayCheckins()`를 호출한다:
    1. 마운트 시 1회 — 기존 드래프트 복구 `useEffect`와 **별도의** `useEffect(() => { reloadTodayCheckins(); }, [reloadTodayCheckins])`로 둔다. 드래프트 복구 effect의 본문을 건드리면 checkin-wiring Test 27/64/65/66의 정규식 앵커(`let isMounted = true;\s*loadRecoverableDraft ... }, [db]);`)가 깨진다 — 그 블록은 손대지 않는다.
    2. `commitCheckin(...).then(result => ...)`의 `result.ok === true` 분기에서 `dispatch({ type: 'SAVE_SUCCEEDED', ... })` 직후 — 방금 저장한 체크인이 즉시 핀으로 나타나게 한다.
    3. `handleFinishCheckin`에서 `dispatch({ type: 'DISMISS' })` 직후 — 메모/사진 flush 결과를 리스트 미리보기에 반영한다.
    4. `AppState` 리스너의 `nextAppState === 'active'` 분기 — 백그라운드에 있던 사이 날짜가 바뀌었거나 시간이 흐른 경우를 흡수한다. 기존 `unsavedExitAlertShownRef.current = false; return;` 문장 순서를 유지하고 `return` **앞에** 호출을 넣는다. 이 effect의 deps 배열에 `reloadTodayCheckins`를 추가한다.

    **저장된 핀 렌더.** `<MapView>` 자식으로, 기존 확인 핀 `<Marker>` 블록과 **형제**로 `todayCheckins.map(...)` 마커 목록을 추가한다. 각 마커는 `key={checkin.id}`, `coordinate={{ latitude: checkin.lat, longitude: checkin.lng }}`, `anchor={{ x: 0.5, y: 1 }}`를 쓰고 자식으로 `<View style={styles.pinWrapper}><View style={[styles.pinDrop, styles.pinSaved]} /></View>`를 렌더한다. `draggable`을 주지 않고 `onDragEnd`/`hitSlop`도 주지 않는다(저장된 핀은 조작 대상이 아니다 — 편집은 Phase 5 소관).
