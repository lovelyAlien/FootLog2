    **reanimated import 네이밍.** `import Reanimated, { useAnimatedStyle, useSharedValue } from 'react-native-reanimated';`로 가져온다. default export를 반드시 `Reanimated`로 이름 붙인다 — `Animated`로 쓰면 이미 `react-native`에서 import된 `Animated`(크로스페이드용)를 가려 checkin-wiring Test 46이 깨지고 native driver 크로스페이드가 무너진다. `react-native-gesture-handler`는 화면에서 직접 import하지 않는다(Test 9/39).

    **컨테이너 높이 측정.** 루트 `<View style={styles.screen}>`에 `onLayout`을 붙여 `event.nativeEvent.layout.height`를 `containerHeight` state에 저장한다(`useState<number>(0)`). 이 값은 탭바를 제외한 오늘 탭 콘텐츠 영역 높이이며 시트 스냅 지점과 버튼 오프셋 계산의 공통 좌표계 기준이다. 같은 값이 다시 들어오면 setState를 건너뛰어 불필요한 리렌더를 막는다.

    **시트 위치 공유값.** `const sheetPosition = useSharedValue(0);`을 만들어 `<TodayBottomSheet animatedPosition={sheetPosition} />`에 넘긴다. 이 값은 시트 상단의 y좌표(컨테이너 상단 기준)이므로, 시트 상단으로부터의 화면 하단 오프셋은 `containerHeight - sheetPosition.value`다.

    **버튼 오프셋 애니메이션 스타일.** `const floatingButtonStyle = useAnimatedStyle(() => ({ bottom: containerHeight - sheetPosition.value + spacing.lg }), [containerHeight]);`를 만든다. `spacing.lg`(24)는 04-UI-SPEC.md §Spacing Scale이 "플로팅 버튼과 바텀시트 현재 상단 사이 간격(D-05 기준값)"으로 확정한 값이다. `onChange(index)` 같은 이산 콜백에 의존하지 않는다 — 드래그 중 손가락을 실시간으로 따라가야 한다(04-UI-SPEC.md DRAGGING 정의). `containerHeight`가 아직 0이면 `useAnimatedStyle`이 음수 bottom을 만들 수 있으므로, `containerHeight <= 0`인 동안은 기존 정적 오프셋(`insets.bottom + spacing.xl`)으로 폴백하는 분기를 워크릿 안에 둔다.

    **JSX 분기 재구성.** 기존 `showActionCard ? A : B` 삼항 구조를 유지하되 B 분기를 다음 순서로 바꾼다(뒤에 오는 것이 위 레이어):

    2. 체크인 버튼 컨테이너 — `<View>`를 `<Reanimated.View>`로 바꾸고 style을 `[styles.checkinButtonContainer, floatingButtonStyle]`로 준다. 내부의 `Pressable`/`Animated.View`(RN 크로스페이드)/`ActivityIndicator`/`Text` 구조는 **한 줄도 바꾸지 않는다**.
    3. 재센터 버튼 컨테이너 — 동일하게 `<Reanimated.View>` + `[styles.recenterButtonContainer, floatingButtonStyle, { right: spacing.lg }]`.
    A 분기(체크인 진행 중)는 Task 1의 결정에 따른다: option-a면 현재 그대로 액션 카드만 렌더, option-b면 재센터 버튼을 함께 렌더하고 그 오프셋은 `insets.bottom + spacing.xl` 정적 값을 쓴다(시트가 없으므로 `floatingButtonStyle`을 쓰지 않는다).
