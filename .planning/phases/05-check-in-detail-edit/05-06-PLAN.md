<objective>
상세화면의 사진 슬롯에 **교체와 삭제** 인터랙션을 붙인다(D-03). 사진을 탭하면 기존 체크인
캡처 흐름과 동일한 액션시트(촬영/앨범에서 선택)로 교체되고, 사진 우상단의 작은 삭제 배지를
탭하면 확인 없이 즉시 제거되어 "사진 없음 + 추가 버튼" 상태로 돌아간다(D-04).

`product-design.md`는 "사진(있으면 표시, 없으면 추가 버튼)"까지만 명시했고 편집 흐름은
스펙에 없던 gap이었다 — 05-CONTEXT.md 논의에서 확정됐다.

Purpose: 사진 삭제는 체크인 전체 삭제(4초 undo 스낵바)와 **명확히 다른 무게의 액션**이다.
사진 필드 하나만 바뀌는 가벼운 편집이라 되돌림 장치를 만들지 않는다(D-04) — 두 삭제를 같은
컴포넌트/패턴으로 묶으려는 시도를 명시적으로 거부한다. 또한 메모와 달리 사진 변경은 dirty
추적 대상이 아니라 **즉시 저장**된다(05-UI-SPEC.md 저장 트리거 매트릭스).
Output: 완결된 사진 편집 흐름 + 파일 원자성 순서 보장 + 회귀 가드.
</objective>
