<objective>
`(tabs)/index.tsx`를 `(tabs)/index/{_layout,index}.tsx` 폴더 구조로 재구성해, 오늘 탭
안에서 상세화면을 push하면서도 탭바가 계속 보이는 nested Stack 셸을 만든다
(product-design.md "네비게이션 셸" 절: 상세화면은 push + 탭바 노출 유지, 설정과 동급).

이 plan은 이번 phase의 **모든 후속 작업이 밟고 서는 땅**이다 — 05-RESEARCH.md Pitfall 1이
경고한 대로 이 이동은 기존 회귀 가드 테스트 5개 파일(경로 상수 6곳)을 한꺼번에 깨뜨리므로,
이동과 경로 갱신을 같은 plan 안에서 원자적으로 끝낸다. 화면 로직은 단 한 줄도 바꾸지 않는다.

Purpose: expo-router는 "탭 폴더 밖으로 push하면 Tabs 네비게이터 전체가 화면에서 사라져
탭바도 함께 사라진다". 탭바를 유지하려면 탭 세그먼트 자체를 `_layout.tsx`(Stack)를 가진
서브 디렉토리로 만드는 방법밖에 없다(05-RESEARCH.md Pattern 1, Expo 공식 문서로 검증됨).
Output: 이동된 오늘 뷰 + 새 nested Stack 레이아웃 + 갱신된 회귀 가드 5개 파일.
</objective>
