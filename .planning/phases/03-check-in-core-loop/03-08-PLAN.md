## 03-UI-SPEC.md 확정 계약 (그대로 구현)

**상태 전이표:**

| 상태 | 트리거 | 카드 내용 |
|------|--------|-----------|
| CAPTURING | 체크인 버튼 탭 | 카드 없음 — 버튼 자체가 로딩 상태, 지도는 계속 보임 |
| CONFIRM | GPS 캡처 완료(성공/타임아웃/폴백 무관, 항상 도달) | 안내 문구(`helperText`) + "확인" 버튼 |
| SAVING | "확인" 탭 | 180ms 크로스페이드로 `ActivityIndicator`만(텍스트 없음). 자동 재시도 1회는 이 안에서 조용히 일어남 |
| SAVED | insert 성공 | "저장 완료"(`screenTitle`) + 사진 영역 + 메모 입력 영역이 기본 노출 |
| SAVE_FAILED | 재시도까지 실패 | "저장하지 못했어요"(`screenTitle`) + "저장 공간을 확인해주세요"(`helperText`, `textMuted`) + "다시 시도" 버튼. **사진/메모 영역 미마운트** |

**확정 문구:** 확인 CTA `확인` / 핀 안내 `핀을 옮겨 위치를 조정할 수 있어요` / 저장 성공 `저장 완료` / 저장 실패 `저장하지 못했어요` / 실패 보조 `저장 공간을 확인해주세요` / 재시도 `다시 시도` / 메모 placeholder `지금 여기서 뭘 하고 있나요?` / 사진 placeholder 라벨 `사진 추가` / 사진 실패 `사진을 추가하지 못했어요` / 미저장 이탈 Alert `이 체크인은 저장되지 않았어요`

**색상 계약:** "확인"/"다시 시도" 버튼은 `colors.accent`를 **쓰지 않는다** — `colors.textPrimary` 배경 + `colors.surface` 텍스트 필 버튼(priming.tsx 선례). `colors.accent`는 체크인 알약버튼(03-09)과 확인 핀에만 쓴다.
