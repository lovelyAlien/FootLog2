## 지도 스타일 토큰 결정 (03-UI-SPEC.md 확정, 이 plan이 코드로 고정)

`DESIGN.md`/`tokens.ts`의 `colors.mapLand` / `colors.mapRoad` / `colors.mapWater` 3개 토큰은 **이 화면에서 사용하지 않는다**. 근거: `react-native-maps`의 `customMapStyle` prop은 Google Maps provider(`PROVIDER_GOOGLE`) 전용이고, 03-RESEARCH.md가 채택한 기본 provider는 API 키가 필요 없는 Apple Maps(provider 미지정)다. Apple Maps는 이 3개 색상으로 지도 베이스(땅/도로/물)를 커스터마이징할 방법을 제공하지 않는다. 따라서 iOS 기본 Apple Maps 스타일을 그대로 쓰고, `colors.accent`/`accentSoft`는 지도 위에 얹는 확인 핀에만 적용해 토큰 계약을 지킨다. 이 gap의 최종 처리(2단계에서 `PROVIDER_GOOGLE` 전환 또는 3개 토큰 폐기)는 Phase 3 스코프가 아니며, 이 plan은 **회귀 테스트로 3개 토큰의 지도 적용을 금지**하는 것으로 결정을 고정한다.

    **확인 핀 렌더링** (`phase === 'CONFIRM' | 'SAVING' | 'SAVED' | 'SAVE_FAILED'` 이고 `pin !== null`일 때):
    `MapView` 자식으로 `<Marker draggable coordinate={{ latitude: pin.lat, longitude: pin.lng }} anchor={{ x: 0.5, y: 0.5 }} onDragEnd={...} />`를 렌더링한다. `react-native-gesture-handler`로 지도 팬과의 우선순위를 직접 조정하지 않는다 — MapKit이 네이티브 레벨에서 이미 중재한다(03-RESEARCH.md Pattern 5).

    핀 시각 상태는 `Marker`의 커스텀 자식 `View`로 그린다(03-UI-SPEC.md §Pin Visual States, 24px 지름 원):
    - `locationSource === 'gps_auto'`: `backgroundColor: colors.accent`, 테두리 없음
    - `locationSource`가 `'gps_low_accuracy_fallback' | 'manual_denied' | 'manual_no_signal'`: `backgroundColor: colors.accentSoft`, `borderWidth: 2`, `borderColor: colors.accent`
    - `locationSource === 'gps_dragged'`: `backgroundColor: colors.accent`, `borderWidth: 2`, `borderColor: colors.accentSoft`
    핀 자체는 24px이되 `hitSlop`으로 드래그 히트 영역을 44×44pt까지 확장한다. 경고 아이콘/문구를 붙이지 않는다(시맨틱 컬러 부재 원칙).

    **드래그 핸들러** (`onDragEnd`):
