  <how-to-verify>
    Task 1의 빌드 URL로 Dev Client를 iPhone에 설치한 뒤(기존 것을 덮어쓰기) 다음 5가지를 순서대로 확인하고 각 항목의 통과/실패를 알려주세요.

    **1. 부팅 + 네이티브 모듈 로드**
    앱을 실행합니다. 크래시 없이 전체화면 지도가 뜨고 하단 중앙에 올리브그린 "체크인" 알약버튼이 보이면 통과입니다. (빨간 에러 화면이 뜨면 어떤 모듈에서 났는지 메시지를 알려주세요.)

    **2. 위치 권한 프롬프트 문구 + 확인 핀**
    "체크인"을 탭합니다.
    - iOS 위치 권한 다이얼로그에 "체크인 위치를 기록하려면 위치 정보가 필요해요."라는 한국어 문구가 보이는지 확인합니다(영어 기본 문구가 보이면 실패).
    - 허용을 누르면 몇 초 안에 지도에 작은 올리브그린 원형 핀이 떨어지고 하단 카드에 "핀을 옮겨 위치를 조정할 수 있어요" 안내와 "확인" 버튼이 뜨는지 확인합니다.

    **3. 확인 핀 드래그 vs 지도 팬 (03-RESEARCH.md A4 검증)**
    - 핀을 손가락으로 길게 눌러 드래그합니다. **핀만 움직이고 지도가 함께 스크롤되지 않아야** 합니다.
    - 드래그를 놓으면 핀 외곽에 옅은 링이 생기는지 확인합니다(사용자 확인 상태).
    - **드래그를 놓은 직후 곧바로 "확인" 버튼을 탭합니다.** 반응이 없거나 한 번 더 눌러야 하면 실패로 기록해주세요(Android 커뮤니티 이슈 `react-native-maps#3777`의 iOS 재현 여부 확인).

    **4. 비행기모드 저장 + 앱 재시작 생존 (product-design.md T3 검증 기준)**
    - 비행기모드를 켭니다(GPS 자체는 비행기모드에서도 동작하지만 네트워크는 끊깁니다).
    - "체크인" → "확인"까지 진행해 "저장 완료"가 뜨는지 확인합니다.
    - 메모에 아무 문장이나 입력하고, 사진 영역을 탭해 액션시트에 "사진 촬영"/"앨범에서 선택"/"취소" 3개가 뜨는지 확인합니다. "앨범에서 선택"으로 사진을 하나 고릅니다(사진 권한 다이얼로그에 "체크인에 사진을 첨부하려면 사진 보관함 접근이 필요해요."가 보이는지도 확인).
    - **앱을 완전히 강제종료**(앱 스위처에서 위로 밀어 종료)한 뒤 다시 실행합니다. 앱이 크래시 없이 뜨는지 확인합니다.
    - 비행기모드를 해제합니다.

    **5. 드래프트 복구 + 사진/메모 차단**
    - "체크인"을 탭해 확인 핀이 뜬 상태에서 **"확인"을 누르지 않고** 앱을 강제종료합니다.
    - 앱을 다시 실행합니다. 확인 핀 화면(핀 + "확인" 버튼)이 자동으로 복구돼 있으면 통과입니다.
    - 이 복구된 확인 핀 화면에 **사진/메모 입력 영역이 보이지 않아야** 합니다(저장 전이므로). 보이면 실패로 기록해주세요.

    각 항목의 결과와, 실패한 경우 무엇이 어떻게 달랐는지 알려주세요. 화면이 스펙과 다르게 보이는 부분(색, 문구, 간격)도 함께 적어주시면 좋습니다.
  </how-to-verify>
